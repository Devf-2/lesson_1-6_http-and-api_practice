# Практика к семинару 1-6 «HTTP и API»

За 50 минут вы запустите собственный учебный API и подключите к нему готовый frontend.

Это **практика на занятии**, а не домашняя работа. Верстка и оформление уже подготовлены. Основная работа пройдет в терминале, `backend/db.json` и `frontend/script.js`.

## Что получится

К концу занятия приложение будет уметь:

- получать список заявок с API через `GET`;
- преобразовывать `Response` в данные JavaScript;
- показывать состояния загрузки, результата, пустого списка и ошибки;
- отправлять новую заявку через `POST`;
- сохранять ее в `backend/db.json`;
- показывать запросы и ответы во вкладке Network.

## План на 50 минут

| Время | Блок | Видимый результат |
| --- | --- | --- |
| 00:00–10:00 | 1. Запуск API | URL `/applications` возвращает JSON |
| 10:00–20:00 | 2. `GET` и JSON | данные API видны в Console |
| 20:00–30:00 | 3. Рендер и состояния | карточки появляются на странице |
| 30:00–40:00 | 4. Ошибки и Network | интерфейс показывает ошибку, запрос разобран в DevTools |
| 40:00–50:00 | 5. `POST` | новая заявка появляется на странице и в `db.json` |

Следующий блок использует результат предыдущего. Сначала выполняйте обязательную часть и только потом переходите к дополнительным заданиям.

Бонусные задания **не входят в обязательные 50 минут** и не влияют на прохождение базовой практики. Они предназначены для тех, кто закончил все пять блоков и хочет усложнить работу.

## Перед началом

Понадобятся:

- Node.js версии `22.12` или новее;
- npm;
- VS Code с расширением Live Server;
- браузер с DevTools.

Проверьте Node.js и npm:

```bash
node --version
npm --version
```

## Запуск проекта

### Терминал 1 — API

```bash
cd backend
npm install
npm run dev
```

Не закрывайте этот терминал до конца практики. API работает по адресу:

```text
http://localhost:3000/applications
```

### Frontend — Live Server

1. Откройте `frontend/index.html` в VS Code.
2. Запустите файл через **Open with Live Server**.
3. Откройте DevTools → **Console** и **Network**.

Не открывайте `index.html` двойным кликом: используйте Live Server.

## Как не потерять темп

- После каждого небольшого изменения проверяйте результат.
- Следите сразу за страницей, Console, Network и терминалом API.
- Если задание заняло больше трех минут, зафиксируйте проблему и двигайтесь вместе с группой.
- Не меняйте дизайн: на занятии оценивается путь данных.
- Не копируйте весь файл целиком — добавляйте код в соответствующий `TODO`.

## Что показать преподавателю

1. В браузере открыт список заявок.
2. В Network виден успешный `GET /applications` со статусом `200`.
3. При временно неверном URL интерфейс показывает понятную ошибку.
4. После отправки формы виден `POST /applications` со статусом `201`.
5. Новая заявка есть на странице и в `backend/db.json`.
6. В Console нет необработанных красных ошибок.

Бонусы показываются отдельно после основной демонстрации. Неработающий бонус не уменьшает результат за корректно выполненную базовую часть.
